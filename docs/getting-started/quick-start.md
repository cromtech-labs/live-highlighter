# Quick Start

Get up and running with Live Highlighter in just a few steps.

## Creating Your First Rule

1. **Open the extension**
   - Click the Live Highlighter icon in your browser toolbar
   - The popup window will appear

2. **Create a rule**
   - Click "Create First Rule" or "Manage Rules"
   - Enter the text you want to highlight (e.g., "production")
   - Choose a colour from the 6 available options
   - Click "Save"

3. **See it in action**
   - Visit any webpage
   - Your highlighted text will automatically appear with your chosen colour

## Managing Your Rules

### Reordering Rules

Rules are processed in order from top to bottom. If text matches multiple rules, the first matching rule wins.

To reorder rules:

1. Open the Live Highlighter popup
2. Click "Manage Rules"
3. Drag and drop rules to reorder them
4. Changes are saved automatically

### Toggling Rules

You can temporarily disable rules without deleting them:

1. Open the rule management interface
2. Click the toggle switch next to any rule
3. Disabled rules won't highlight text until re-enabled

### Deleting Rules

To remove a rule you no longer need:

1. Open the rule management interface
2. Click the delete icon (trash can) next to the rule
3. Confirm the deletion

## Example: Highlighting Environments

Let's set up a practical example for cloud environment management:

1. Create a rule for "production" with red highlight
2. Create a rule for "staging" with yellow highlight
3. Create a rule for "dev" with green highlight
4. Visit your cloud console

Now environment names will automatically pop with colour, helping you avoid costly mistakes.

## Tips for Effective Highlighting

- **Be specific:** Highlight unique identifiers rather than common words
- **Use meaningful colours:** Red for danger/production, yellow for caution/staging, green for safe/dev
- **Don't over-highlight:** Too many rules can make pages cluttered
- **Order matters:** Place more specific rules above general ones
