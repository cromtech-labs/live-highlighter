## Reporting Bugs

Found a bug? Please report it on GitHub:

1. Go to our [GitHub Issues page](https://github.com/cromtech-labs/browser-highlighter/issues)
2. Search existing issues to see if it's already reported
3. If not found, click "New Issue"
4. Choose "Bug Report" template
5. Provide as much detail as possible:
   - Browser and version
   - Operating system
   - Steps to reproduce the bug
   - Expected behavior
   - Actual behavior
   - Screenshots (if applicable)

### What Makes a Good Bug Report

**Good Example:**

```
**Browser:** Chrome 120.0.6099.109
**OS:** Windows 11
**Steps to reproduce:**
1. Create a rule for "test" with red highlight
2. Navigate to example.com
3. The word "test" appears but is not highlighted

**Expected:** The word should be highlighted in red
**Actual:** No highlighting appears

**Screenshot:** [attached]
```

**Not Helpful:**

```
It doesn't work
```

## Feature Requests

Have an idea for a new feature? We'd love to hear it!

1. Go to our [GitHub Issues page](https://github.com/cromtech-labs/browser-highlighter/issues)
2. Search existing issues to see if it's already suggested
3. If not found, click "New Issue"
4. Choose "Feature Request" template
5. Describe:
   - The feature you'd like
   - Why it would be useful
   - How it should work
   - Any examples or mockups

### Popular Feature Requests

Check if your idea is already on our radar:

- Website-specific rules
- Import/export functionality
- Regular expression support
- Cross-device sync
- Firefox and Safari support

## Getting Help

### Before Asking for Help

1. Check the [FAQ](../reference/faq.md)
2. Search existing GitHub issues
3. Try the troubleshooting steps in the relevant documentation

### How to Ask for Help

When asking for help, please provide:

- What you're trying to do
- What you've tried so far
- Browser and version
- Operating system
- Screenshots or error messages (if applicable)
- Steps you've taken to troubleshoot

### Response Time

Live Highlighter is an open-source project. Response times vary, but we try to:

- Acknowledge issues within 48 hours
- Respond to questions within a week
- Fix critical bugs as quickly as possible

## Commercial Support

Live Highlighter is a free, open-source project. Commercial support is not currently available.

If your organization needs custom features or dedicated support, you can:

- Fork the repository and modify it for your needs (MIT License)
- Hire a developer to customize it
- Contact the maintainers to discuss custom development

## Security Issues

Found a security vulnerability? Please **do not** open a public issue.

Instead:

1. Email the maintainers (contact info in GitHub profile)
2. Provide details about the vulnerability
3. Allow time for a fix before public disclosure

We take security seriously and will respond quickly to security reports.
