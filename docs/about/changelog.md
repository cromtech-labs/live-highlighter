# Changelog

All notable changes to Live Highlighter will be documented in this file.

## [0.1.0] - 2024-12-24

### Initial Release

**Status:** Beta - Open for feedback

This is the first public release of Live Highlighter. The extension allows you to highlight user-defined strings on any webpage with configurable colours.

### Features

- ✨ Create multiple highlight rules with custom text and colours
- 🎨 Choose from 6 carefully selected colours
- 🔄 Drag and drop to reorder rules
- 🔘 Toggle rules on/off without deleting them
- 🌐 Works on all websites and web applications
- 🔒 Complete privacy - all data stored locally
- ⚡ Fast and lightweight performance

### Technical Details

- Built with Manifest V3
- Supports Chrome 105+ and Edge 105+
- Local storage for rule persistence
- Works in all frames (including iframes)

### Known Limitations

- Rules apply globally to all websites (website-specific rules coming in future release)
- Exact text matching only (case-sensitive)
- No import/export functionality yet

**Feedback Welcome:**
We're actively seeking feedback to improve the extension. Please report bugs or suggest features on our [GitHub Issues](https://github.com/cromtech-labs/browser-highlighter/issues) page.

## How to Update

Live Highlighter updates automatically through the Chrome Web Store or Edge Add-ons. You can also manually check for updates:

1. Go to `chrome://extensions` or `edge://extensions`
2. Enable "Developer mode"
3. Click "Update" at the top

Your highlight rules will be preserved across updates.
